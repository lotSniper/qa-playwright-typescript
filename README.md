# Playwright TypeScript QA Automation

A small QA automation project built with Playwright and TypeScript.

The repository is used to practice and demonstrate practical UI test automation skills, including test design, locators, assertions, reusable test structure, and browser automation.

## Tech Stack

- Playwright
- TypeScript
- Node.js
- Git / GitHub

## Covered Testing Areas

- UI functional testing
- End-to-end scenarios
- Regression testing
- Cross-browser testing
- Form and user interaction testing
- Playwright locators and assertions

## Current Test Scenarios

### TodoMVC

- Create a todo item
- Mark a todo as completed
- Delete a todo item

More scenarios will be added as the project develops.
